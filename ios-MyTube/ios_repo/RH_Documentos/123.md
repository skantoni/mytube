🔴 CORRECÇÕES CRÍTICAS (bugs activos)

1. Bug contador de comentários
Ao apagar um comentário pai com respostas, o contador do vídeo só desconta 1 em vez de (1 + total de respostas). Exemplo: vídeo com 10 comentários, ao apagar 1 pai com 3 respostas, passa para 9 em vez de 6.

2. Ficheiros administrativos expostos publicamente
Existem ~23 ficheiros na raiz (install_*.php, migrate_*.php, test_*.php, update_database.php) acessíveis via browser sem autenticação. Qualquer pessoa pode executar scripts que modificam a base de dados. Fazer os famosos SQL injection 

3. Dados reais no repositório público
O ficheiro database/mytube_structure.sql contém hashes de senhas e e-mails reais de utilizadores. Deve ser substituído por um SQL limpo apenas com estrutura e dados fictícios.

---

🟡 MELHORIAS PLANEADAS

4. Contador de comentários em tempo real
Actualmente usa polling periódico. A sugestão é expandir o chat-server (Node.js já existente) para emitir eventos de contagem via WebSocket.

5. Protecção dos ficheiros administrativos via .htaccess
Bloquear acesso público a todos os ficheiros test_*, install_*, migrate_*, fix_*, check_* e update_*.

6. Configuração de sessões para Safari/iPhone
Adicionar session_set_cookie_params() com SameSite=None; Secure antes do session_start() para resolver problemas de login em iOS.
